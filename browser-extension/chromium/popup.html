MediaGrab

Browser media capture

Background detection is off by default.

Scan the current page for media resources, subtitle tracks, and downloadable links.

    Background detection is optional and requires access to all HTTP(S) sites to observe cross-origin media CDNs. It reads response Content-Type only, stores candidates in memory for this browser session, and never reads request headers or response bodies. Scanning remains user-triggered when background detection is off.
